CHECK THE ACS VOUCHER OF AN ORDER

A voucher request for order #1234 may have reached ACS, but no answer came back. ACS may have created a voucher, so no new request is sent until you check.

What happened: ACS [ACS_Create_Voucher]: ACS timeout after 15s: Read timed out.

Look in the ACS portal for a voucher of order #1234 (its reference is the order number). Then open the order's ACS shipment: if you found one, use “Adopt ACS voucher” and enter its number; if there is none, use “No voucher at ACS: request again”.
